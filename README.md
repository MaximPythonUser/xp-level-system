 Level-Up 

Простой модуль для проверки повышения уровня в игре.

## Что делает

Функция `is_leveled_up` проверяет, достаточно ли суммарного опыта (текущий + полученный) для перехода на следующий уровень.

## Как это работает

- **Константа:** `DEFAULT_LEVEL_EXPERIENCE = 200` — порог опыта для повышения уровня.
- **Логика:** Складывает `current_experience` и `gained_experience`. Если сумма больше или равна порогу — возвращает `True`.

Суть в том, что есть фиксированный порог опыта (200 единиц), и функция is_leveled_up просто проверяет, хватает ли у игрока суммарного опыта (текущий плюс новый) для повышения уровня. Если хватает — возвращает True, если нет — False.

Это стартовая логика: она пока не учитывает разные пороги для разных уровней и не сохраняет остаток опыта, но отлично подходит как первый шаг или как основа, которую потом можно усложнить.
